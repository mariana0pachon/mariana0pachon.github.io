corrientes

Commands:
space new image
↑ ↓ scan speed
or drop anywhere

A red line scans the image left to right, sampling the average RGB of each column to drive three sine voices:
red → pitch of a short tone
green → pitch of a kick
blue → pitch of a slow sine

Originally built with Processing and PurrData.

The original Processing code sent RGB over OSC to a PurrData patch with cells created by Xavi Manzanares (@xamanza).

Translated to Canvas API and Web Audio API with the help of Claude AI.
